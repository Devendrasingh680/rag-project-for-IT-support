# Password and Account Access Policy

## Password Requirements
Minimum 14 characters, must include one number and one symbol. Passwords expire every 90 days.
Password history: cannot reuse last 10 passwords.

## Self-Service Password Reset
Users can reset their own password via the Self-Service Portal (sso.corp.internal/reset) if they have
previously enrolled a recovery phone number or personal email. Enrollment happens automatically at onboarding.

## Account Lockout
Accounts lock after 5 failed login attempts within 15 minutes. Lockout duration is 30 minutes, or an
IT admin can manually unlock via Active Directory Users and Computers.

## IMPORTANT — Escalation Required
Password resets and account unlocks for accounts flagged as "Privileged Access" (Domain Admins, Finance
system owners) require a support ticket to be escalated to a Tier 2 technician and CANNOT be performed
through self-service or by a Tier 1 agent, human or automated.
